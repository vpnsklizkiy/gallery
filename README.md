# Быстрая фотогалерея для GitHub Pages

## Самый простой способ обновления

1. Кладёте полноразмерные оригиналы в `photos/`.
2. Дважды запускаете `update-gallery.bat` на Windows.
3. Скрипт автоматически создаёт лёгкие превью в `previews/` и обновляет массив `PHOTOS` в `script.js`.
4. Загружаете изменения на GitHub: `photos/`, `previews/`, `script.js`.

Оригиналы не изменяются. Именно файлы из `photos/` используются для скачивания.

## Как работает скорость

- Сетка показывает только уменьшенные файлы из `previews/` и использует `loading="lazy"`.
- При открытии фото сначала мгновенно показывается превью.
- Параллельно браузер загружает оригинал и автоматически подменяет им превью.
- Предыдущее и следующее полноразмерные фото предзагружаются в фоне.
- Кнопка «Скачать» и массовое скачивание всегда используют оригиналы из `photos/`.

# Простая фотогалерея для GitHub Pages

Статический сайт на чистых HTML + CSS + JavaScript.

## Как добавить фотографии

1. Скопируйте фотографии в папку `photos/`.
2. Откройте `script.js`.
3. В самом верху найдите массив `PHOTOS`.
4. Впишите имена файлов, например:

```js
const PHOTOS = [
  "IMG_001.jpg",
  "IMG_002.jpg",
  "IMG_003.webp",
];
```

Имена чувствительны к регистру на GitHub Pages: `Photo.JPG` и `photo.jpg` — разные имена.

## Как проверить локально

Можно просто открыть `index.html` в браузере. Для максимально точной проверки лучше запустить локальный HTTP-сервер, например через расширение Live Server в VS Code.

## Как выложить на GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните.

## Возможности

- адаптивная галерея;
- полноэкранный просмотр;
- предыдущее/следующее фото;
- приближение колесом мыши и кнопками;
- перемещение увеличенного изображения;
- двойной клик для быстрого зума;
- скачивание одной фотографии;
- выделение нескольких фотографий;
- выбрать/снять выделение со всех;
- последовательное скачивание выбранных фотографий;
- клавиши ← →, Esc, +, -, 0.

### Почему список файлов задаётся в `script.js`

GitHub Pages — статический хостинг. Браузеру нельзя просто запросить содержимое папки `photos/`, поэтому список файлов необходимо задать явно (или генерировать его заранее отдельным скриптом при сборке).
